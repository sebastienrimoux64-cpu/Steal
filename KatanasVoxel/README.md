# Katanas en voxel – Blender

4 katanas voxel (~860 voxels, 1 voxel = 1,2 cm, ~1,1 m de haut) : bois (bokken), fer, or, diamant.
Lame courbée avec tranchant éclairé, kissaki (pointe), tsuba (garde), habaki, manche à motif de losanges, pommeau.

- `Katana_<Matière>_Voxel.blend` / `.fbx` / `.glb` : un katana par fichier (origine = bout du manche, lame vers +Z).
- `Katanas_Voxel_All.blend` : les 4 ensemble. `Previews/` : rendus.

Régénérer : `python tools/katanas/make_voxel_katanas.py`.
